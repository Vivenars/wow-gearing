# 魔兽世界配装模拟器 · 正式服与无限服

[打开配装器](https://vivenars.github.io/wow-gearing/) · [直接进入无限服](https://vivenars.github.io/wow-gearing/forever.html)

## 1.2.0 · 无限服配装器

页面左上角可切换正式服／无限服，两种服的方案独立保存在当前浏览器。正式服保留 12.1.5 的装备、宝石附魔、属性比较与 SimC 功能。

无限服支持 9 职业、1–60 级、17 个装备部位（含远程／圣物），以及装备搜索和筛选、逐项属性来源、换装比较、自定义装备、手动附魔与增益、多方案保存和 JSON 导入导出。

装备库包含 13,606 条记录：优先读取本机无限服 1.60.1.70959 中文客户端及官方热修，少量未缓存装备引用独立的 Forever 物品数据库。部分记录标记待核实，不使用 Classic Era 同 ID 数值替代。无限副本手册仅用于本地核对范围，未复制其代码或数据。

页面内可下载“无限配装导出 1.0.0”，安装后在游戏中输入 `/igw`，将文本粘贴到无限服的“导入角色／方案”。未识别的附魔需在网页填写。导出插件尚未进行真实游戏客户端验证。

属性概览为装备、附魔与手动增益贡献。角色基础、主属性换算、天赋、套装、条件触发效果和 DPS/HPS 暂不自动计算。原理与来源说明可在网页查看。发布前本地主项目 92 项测试通过。

## 发布方式

本仓库沿用 `site.zip` 发布：`.github/workflows/pages.yml` 解压压缩包，运行其中的 `scripts/verify-static.mjs`，再发布 `site/dist/` 到 GitHub Pages。更新 `main` 上的 `site.zip` 会自动触发发布。

网站是纯静态页面，不需要运行时依赖、服务器账号或 API 密钥。压缩包不含服务器配置、SSH 密钥、游戏账号或登录凭据。

方案仅保存在当前网址和浏览器中；原服务器网站与 GitHub Pages 的存档不互通，迁移前请导出 JSON 备份。
